BLACK ROCK SHOOTER: THE GAME - the PC port
==========================================

This is a new program that plays the PSP game on a PC. It has none of the
game in it: it reads the game from a disc image (.iso) of your own copy.
The port was made against the US release (NPUH-10126).

You need no command line and nothing else installed.


SETTING IT UP (once)
--------------------

1. Put  brs-game.exe  in the folder you want the game in. The game is made
   beside it and takes about 1.4 GB.

2. Double-click  brs-game.exe . The first time, a window opens that says
   "Drop the game's disc image (.iso) here".

3. Drag the .iso of your copy of the game onto that window and let go.
   (Or click the window and choose the .iso. Or skip step 2 and drag the
   .iso straight onto  brs-game.exe .)

4. Wait a few minutes. The window says what it is doing, with a bar:
     1 of 3  copying the films
     2 of 3  unpacking the game
     3 of 3  making the music and the voices playable   (the longest part)
   If the PC has no "ffmpeg" (the program that decodes the game's sound),
   it is fetched by itself from gyan.dev (about 115 MB) into the game's
   folder. That needs the internet, this once.

5. The game starts by itself when it is ready.

The window can be closed at any time: the next time brs-game.exe is opened
it goes on where it was. Your .iso is only read, never changed.


PLAYING
-------

Double-click  brs-game.exe . Once the game is made, that starts it.

   Stick or WASD ........ move
   Arrow keys / mouse ... camera
   A controller works too.

Saves are kept in the "save" folder beside the game.


IF SOMETHING GOES WRONG
-----------------------

"this is not a disc image"
    The file is not an .iso. A compressed one (.cso) has to be made an
    .iso first (the emulator PPSSPP can do that, for one).

"The game is ready, but without its sound"
    ffmpeg could not be fetched (no internet, most likely). The game can be
    played silent. For the sound, drag the .iso onto  brs-game.exe  again
    when the internet is there: it only does what is still missing.

It cannot write where it is
    Move  brs-game.exe  to a folder of your own (Documents, the desktop,
    another drive) and not one of Windows' own, and open it there.

Windows warns about an unknown program
    The program is not signed. "More info" > "Run anyway" starts it.
